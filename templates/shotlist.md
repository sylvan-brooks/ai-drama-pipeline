# 分镜表模板

一集拆成若干段，每段的长度按视频模型一次能生成的上限来。一段一张表，填完再写这一段的生成提示词。

## 第 N 段 · 起止 00:00–00:__

**这一段要让观众知道什么**：（一句话。写不出来，说明这段可以删。）

**场景**：（定场图：`refs/scene_x.png`）

| 1 | | | | | |

| 3 | | | | | |
| 4 | | | | | |

**硬切点**（给 `upscale60.py --cuts`，单位秒）：

**这一段不能出现的**：（错的道具、多余的人、文字水印……）

## 出片前自查

- [ ] 关掉声音看，每个镜头能看懂发生了什么
- [ ] 定妆图和场景图已经和对标作品的帧并排比过
- [ ] 每个角色的音色都试听确认过
- [ ] 打样（低分辨率）看过，动作、顺序、人物长相都对，再出定稿
- [ ] 预估花费算过（`gen.py` 会按 `providers.json` 的单价报）
